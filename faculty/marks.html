CT & Exam Marks

Four class tests (each /20, best three count), assignment/quiz/presentation (/10) and the final (/60).

—

Total = best 3 CTs (/20) + attendance (/10) + assignment/quiz/presentation (/10) + final (/60)

CT model: { id, studentId, courseId, testNumber, marks }. A/Q/P model: { id, studentId, courseId, marks }. Final model: { id, studentId, courseId, marks }. The attendance column is read-only — it comes from the Attendance sheet (percentage ÷ 10). Leaving a box empty means "not taken" and stores nothing.

If you have set up a question paper for a class test (or for the final) on the Question Setup page, that column turns read-only: its total is added up from the question marks instead. Use the enter Q-wise link in the column heading to open the question grid, which is laid out like the department's marks spreadsheet. Papers with no questions keep the simple one-box entry.
