Faculty user model: { id, role:'faculty', name, email, password, designation, departmentId, onLeave }. The link to a course is Course.facultyIds — a list — so one course can be shared by several teachers. Teachers from other departments (Maths, Physics, Humanities) are kept on the External Faculty page.
